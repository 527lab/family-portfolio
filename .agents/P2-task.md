# P2：作品集改為通用、暱稱由創作者自訂（P1 完成後再跑）

## 新需求
1. 網站內容不綁定特定學校或科系：移除所有文案、頁面、metadata、README、種子資料中的學校／科系名稱（中山大學、靜宜大學、亞洲大學、劇場藝術管理、台文系等），改寫成通用的個人作品集（畫作、攝影、鋼琴演奏影片、檢定證書）。
2. 暱稱由她註冊創作者帳號時自己設定：註冊表單加「暱稱」欄位（必填、可於個人設定修改），網站上所有顯示名稱（首頁、作品頁、頁尾、title 等）都改用該帳號暱稱；尚無帳號時顯示中性文字（例如「創作者」），不要寫死任何名字。
3. 全專案移除佔位暱稱「小禾」。

## 限制
- 在 P1 的分支基礎上開新分支 p2-generic，完成後開 PR，PR 寫明怎麼測，不要自行合併。
- npm run build 必須通過；不放真實個資或金鑰；不刪與需求無關的檔案。
